# Personal Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

**Live site:** https://personal-portfolio-one-amber-95.vercel.app *(replace with your Vercel link)*

## Sections
- Home: name, introduction, and tagline
- About Me: personal introduction and education
- Skills: programming and web development skills
- Projects: three completed projects
- Achievements: awards, certificates, and seminars
- Contact Me: email, GitHub, LinkedIn, and a message form

## Features
- Responsive layout for desktop and mobile
- Mobile navigation menu
- Active section highlighting in the navbar
- Animated skill bars
- Contact form that opens the visitor's email app

## Project structure
```
personal-portfolio/
├── index.html
├── style.css
├── script.js
├── images/
└── README.md
```

## Run locally
Open `index.html` in a browser. No build step is needed.

## Deployment
Hosted on Vercel and connected to this GitHub repository. Every push to `main` redeploys the site automatically.
